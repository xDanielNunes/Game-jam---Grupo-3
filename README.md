# Protótipo para Game Jam da Liga Acadêmica WASD

Este projeto é um **protótipo desenvolvido para a Game Jam da Liga Acadêmica WASD**.  
O objetivo desta versão é testar algumas mecânicas principais do jogo, como movimentação, interação com objetos e sistema de inventário.

Por se tratar de um **protótipo**, vários elementos ainda podem ser alterados ou melhorados, incluindo gráficos, balanceamento e funcionalidades.

## Controles

- **W / A / S / D** → Movimentar o personagem  
- **Espaço** → Pular  
- **F** → Interagir com objetos e **consumir itens do inventário**  
- **Tab** → Abrir / Fechar o inventário  

## Observações

- Itens encontrados no cenário podem ser coletados e armazenados no inventário.
- Quando o inventário está aberto, outras ações do jogador ficam desativadas para permitir a navegação entre os itens.

## Status do Projeto

⚠️ Este jogo está em **fase de protótipo** e foi criado para fins de experimentação durante a Game Jam.  
Mudanças e melhorias ainda podem ser feitas nas mecânicas, interface e conteúdo do jogo.
